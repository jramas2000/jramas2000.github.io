Job Agent: Privacy Policy

Last updated: October 18, 2026

Job Agent is a personal tool used only by its owner. It is not available to anyone else.

What data it accesses

With the owner's permission, Job Agent reads the owner's own Gmail messages using the read-only Gmail scope (gmail.readonly). It only looks for job-application related emails, such as application confirmations, recruiter replies, verification codes from job application sites, and job-alert emails.

How the data is used

The data is used only to update the owner's private job-application tracker. Job Agent cannot send, delete, or modify email.

Sharing and storage

No data is sold, shared with, or transferred to any third party. Data is stored only on the owner's private server.

Google API Services User Data Policy

Job Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
